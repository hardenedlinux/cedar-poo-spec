#+OPTIONS: toc:2

* Scope and ownership

The migration covers consumer orchestration throughout =Examples/= and
=CedarPooSpec/=, with =Productions/= included in the import and artifact gates.
It is not a financial-only slice. The immutable LeanPOO revision remains
=b577371fe4e2717e198a29eefe16ec8ae0380e0d=; Cedar and Lean pins are unchanged.
The library and Productions remain independent of Examples and Tests.

| Surface | Actual shared path | Retained domain boundary |
|---------+--------------------+--------------------------|
| Cloud pipeline, deployment and Google SDP | checked Program, typed publication and paired receipts | verified release, actual transformation/key recipe and current source |
| Health prior authorization, regional/FHIR/record access, model stewardship and pseudonymization | checked Program where schemas exist; compile-stage Factory for schema-free diagnostics | patient/channel/region, lineage, keys, incident/recovery and disclosure effects |
| Agent delegation, chain, payment, session, fanout and department | Program authorization/export and shared compound receipts | current request/history, consumption, budgets, independent authorities and final refresh |
| Governance, procurement and tenant/device scenarios | typed preparation, publication and current-request evaluation | owner/veto separation, scoped schema changes, construction conflicts and malformed publication refusal |
| Vehicle mission, Uptane and VLA | checked Programs and ordered exports | attestation, epoch, maintenance and command-effect identity |
| Financial lakehouse, banking, reconciliation and settlement | checked Programs and ordered compound/layer receipts | independent claims/source, ordered workflow, credential requirements and handoff scope |
| BoundOperation, PolicySnapshot and authorization-delta library consumers | compile-stage Functional Factory and existing receipt/cache ownership | original errors, actual policy identity, topology refusal and refresh ordering |
| Productions | existing shared library composition; no legacy consumer dispatcher was present | independent import closure and unchanged Production fixture JSON |

The source gate =just check-functional-consumers= rejects the replaced direct
export and compound-authorization dispatchers in Examples/Productions and library
consumers. Canonical low-level API definitions remain available. Construction,
provenance and negative C4 proofs retain =Model.compile*=; independent Cedar
=isAuthorized= proof oracles remain independent. Removing these would erase the
reference against which the shared orchestration is checked.

* Types and Contracts on actual paths

=Compiled model root= and =Validated model root schema= carry actual policies
and their equations. Schema-bearing consumers use checked =Program= operations.
Schema-free ModelStewardship, MultiHospitalAI and ExtensionCoverage diagnostics
use =Functional.compilation=: a LeanPOO =Factory= producing the existing indexed
compiled witness. This preserves compile-only error behavior without inventing
a schema. The raw ExpandedPolicy exporter also uses this compile-stage path.

=PolicyProfile= now checks setting, inherited render method and computed policy
through a strict ObjectContract before =policy?= returns a value. Refined children
compute from final-self settings; overriding the policy projection inconsistently
is refused. =Admission.Handoff.scope?= similarly checks the complete typed scope
against case/digest projections, nonempty fields and distinct actors.
These Contracts execute in the consumers; they are not documentation-only tags.

=Tests/Functional/WholeMigration.lean= compares shared compound authorization
with an independent original algorithm for arbitrary models, requests and
entities, including complete failures. Six generic compilation/receipt/Contract
laws are restricted to =propext=, =Classical.choice= and =Quot.sound=.
Earlier capability, root-family, effect, reuse and lifecycle proofs remain gates.

* Complete artifact and Rust replay gate

=just check-functional-catalog= emits all 51 official entries under the existing
120-second, 2048-MiB and 10000000-tick limits. The 48 pre-migration files captured from =1336b086ad960574eec1e3366967e2bd10e41a37=
retain their original SHA-256 bytes; three settlement exports extend the catalog.
=Tests/Conformance/functional-manifests.sha256= freezes this boundary.

The existing Rust bridge =replay-catalog= runs official Cedar evaluation for raw
fixtures and strict schema-bound replay where schemas exist. Schema evolution
uses its existing replay. The catalog produces 1280 Cedar replay rows, alongside
the schema-evolution result. Six deployment artifacts must match their schema-bound
source policies and exact deployable-root set. The tabular input is explicitly a
data fixture; it is not reported as a Cedar decision or cryptographic execution.
Unknown shapes, empty Cases and missing cross-artifact bindings fail. The gate
explicitly runs Rust mutation tests on these actual emitted artifacts: substituted
digest/actor, cross-Case links, changed phase/credential order and unsafe deployment
root must fail with their specific diagnostic.

Settlement adds 28 claims and 56 banking request receipts across 14 scenarios,
plus typed cross-domain handoff simulation. Rust parses actors as Cedar
=EntityUid=, compares the complete scope and grant, checks exclusive expiry and
current epoch, binds every linked Case exactly once, and preserves ordered bank
phases/credential requirements. Only =ready= admits; wrong actor/digest/case,
stale/expired grants, unknown/other modes, source/region/context gaps, paused
banking and invalid Contract projections remain independent refusal controls.
The existing financial entrypoint invokes the same selected-catalog replay.

* Qualification boundary

=just check-lean= includes the source guard, all Lean tests, proof audits and
Production fixtures. =just check-rust= retains workspace tests, ASP checks,
clippy and dependency-direction checks. CI also executes the complete catalog
alongside the existing artifact, schema, Host and authorization-delta gates.
Local results and exact-head remote CI are separate receipts.

TableBatch still owns ordered selection, duplicate ordinals and cumulative UTF-8
byte ceilings. Provider adapters own wire/physical-input checks. Host simulations
establish neither authentic external facts, executed settlement/encryption,
durable atomic execution, crash recovery nor process-RSS bounds. PolicyJson
remains a partial exporter. Scoped reuse timings do not establish native or
end-to-end throughput.
