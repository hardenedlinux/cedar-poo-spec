using the =imagegen= skill on 2026-11-05. Exact generation prompts and SHA-256

=financial.png= is the reusable financial-services emblem; =payment.png= is
its payment specialization. The shared TS components live in
=dev/ts/components/financial.ts= and =payment.ts=. They embed these original
raster assets explicitly inside the exported SVG; model topology and all
semantic labels stay native vector content. No regeneration or network fetch
occurs during rendering or CI. Assets are presentation only and do not assert
publisher endorsement, security certification or proof of incident details.

Missing images or a hash mismatch refuse rendering. Export receipts capture
the manifest and the actual binary hashes so changing an image invalidates
publication alongside the existing Lean/SysML/D2 source checks.
